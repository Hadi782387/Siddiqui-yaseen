# Yaseen Siddiqui | Portfolio

React + Vite portfolio. Dark/light theme, scroll animations, responsive.

## Run
npm install
npm run dev

## Edit
All content (name, about, experience, projects, skills, links) is in `src/data.js`.
Add your GitHub and LinkedIn URLs there to show them in the footer.

## Deploy
Resume: replace `public/Yaseen_Siddiqui_Resume.pdf` to update the download.
Vercel: import the repo and click Deploy (no config needed).
